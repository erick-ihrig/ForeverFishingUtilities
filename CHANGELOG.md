# Changelog

## 2.2.1
- `/ffu reset` now says where the window goes: its default spot, centred near the top of the screen.
- Double right-click uses a fixed 0.4 s window; the custom timing option was removed.

## 2.2.0
- The window now only shows while a fishing pole is equipped, by default. `/ffu pole` switches to always showing it.

## 2.1.0
- World map: hovering **any** zone now shows its fishing numbers in a small tooltip (previously only your current zone worked).
- Double right-click casting and fishing sound mode are now **off by default**. Turn them on with `/ffu dblclick` and `/ffu sound`.
- Removed skill-up tracking, manual zone values (`set`, `setzone`, `clear`) and the key commands (`swapkey`, `keys`). Use the Keybindings menu for keys.
- Shorter `/ffu help` that also shows whether each option is on.

## 2.0.0
- Renamed to **Forever Fishing Utilities**. The addon folder is now `ForeverFishingUtilities`.
- The slash command is now `/ffu` (was `/zfs`).
- Settings and keybinds start fresh, because WoW stores them under the old name.

## 1.9.5
- Added `/zfs swapkey <KEY>` to set the swap key without the Key Bindings screen.
- Added `/zfs keys` to show which keys are set.

## 1.9.4
- The orange label now reads "Minimum".

## 1.9.3
- The swap keybind is now a normal entry under Key Bindings → AddOns → Zone Fishing Skill.

## 1.9.0 – 1.9.2
- Space fishing is on by default and stays on across pole swaps. Space jumps whenever no pole is equipped.
- Spacing fixes so the corner icons don't overlap the text.

## 1.8.0
- New pole / weapon swap button and keybind. It works in combat.
- The skill numbers now have labels: Minimum and Recommended.

## 1.7.0
- New best-lure button.
- The window is combat-safe: it only changes its layout out of combat.

## 1.6.0
- Added the "Your Skill" line.
- Hovering a zone on the world map shows its fishing numbers.

## 1.5.0
- New toggle button for fishing sound mode.

## 1.4.0
- Built-in one-key fishing (Space or a keybind), double right-click casting, and fishing sound mode. Better Fishing is no longer needed.

## 1.0 – 1.3
- First versions: zone skill window, subzone exceptions, and skill-up tracking.
